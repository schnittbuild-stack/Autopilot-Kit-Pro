# Testfälle (Evals)

Pro Skill ein Unterordner mit mindestens 3 Fällen, dazu `ketten/` mit 5
Ende-zu-Ende-Durchläufen der Hauptkette.

Diese Fälle sind der eigentliche Graben des Produkts: echte, anonymisierte Fälle
aus der eigenen Beratungspraxis, die kein Wettbewerber kopieren kann.

Regel aus CLAUDE.md: Lieber 4 ehrlich harte Testsätze als 20 geschönte.

# Notfall — wenn etwas klemmt

Fertige Hilfe-Texte zum Kopieren. Du kopierst den passenden Text in deine KI —
sie findet den Fehler selbst und schlägt dir **eine** Lösung vor, bevor sie
etwas ändert.

Noch einfacher: Schreib deiner KI einfach **hilfe**. Dann sucht sie sich den
passenden Text hier selbst heraus.

| Wenn das los ist | nimm |
|---|---|
| Du musstest aufhören und weißt nicht, wie es weitergeht | `01-weiter-machen.md` |
| Der Ton, die Anrede oder die Signatur passen nicht | `02-klingt-nicht-nach-mir.md` |
| Eine Zahl, ein Preis oder ein Fakt stimmt nicht | `03-zahl-oder-fakt-stimmt-nicht.md` |
| Sie findet deine Dateien nicht oder speichert nichts | `04-findet-meine-dateien-nicht.md` |
| Es hängt, wiederholt sich oder du sollst warten | `05-es-geht-nicht-weiter.md` |
| Etwas anderes | `diagnose-allgemein.md` |

**Das Wichtigste vorweg:** Ein abgebrochenes Gespräch ist kein Schaden. Dein
Stand liegt auf deinem Rechner, nicht im Gespräch. In fast allen Fällen genügt
das Wort **weiter**.

Autopilot Kit — Interner Fahrplan

Vom leeren Repo zum verkaufsfähigen Produkt. Ein Kern, ein Funnel, Claude Code zuerst. Klicke auf eine Phase für Aufgaben, Deliverables und Risiken. Haken sind nur für diese Sitzung (kein Speichern).

Zeithorizont: ~4 Wochen bis Launch
Produkt V1: Vertriebspaket, nur Claude Code
Preis: 299 € Intro → 499 € Anker
Team: 2 Personen + eigene Agenten

Die vier Bauprinzipien

Gelten in jeder Phase. Verstöße hier erzeugen die Support- und Drift-Probleme später.

Eine Quelle der Wahrheit

Profil, Firmendaten, Tonalität, Verbote stehen genau einmal (profil.md). Skills referenzieren, nie duplizieren. Kein Agent ändert gemeinsame Dateien selbst.

Zustand auf der Platte

Jede Phase schreibt Fortschritt in STATUS.md. Sessions dürfen jederzeit sterben — nichts geht verloren. Kontextverlust ist kein Ereignis.

Übergabeverträge

Wo Agent A an Agent B übergibt, ist das Format fest definiert. A darf sich intern ändern, ohne B zu brechen. Der Watchdog testet die Ketten, nicht nur Einzelteile.

Kern ≠ Plattform

Inhalt (Skills, Interview, Testfälle) ist plattformneutrales Markdown. Nur die dünne Installationsschicht ist Claude-spezifisch. ChatGPT/Codex wird später ein Adapter, kein neues Produkt.

Phasenplan

Phasen 2–4 überlappen bewusst — Skills, Installer und Tests entstehen ineinandergreifend.

Die zwei Go/No-Go-Gates

Vor diesen Punkten wird kein weiteres Geld und keine weitere Woche investiert.

Gate 1 — nach dem Smoke-Test (Ende Woche 1)

Video-Creative + Landingpage + kleines Ad-Budget laufen, BEVOR das Kit fertig ist. Gemessen wird Kaufabsicht (Vorbestellung 299 €), nicht Klicks.

Weiter, wenn: Klickpreis unter ~1,50 € und Vorbestell-Conversion über ~0,7 %. Sonst: Creative oder Zielgruppe drehen — nicht das Produkt weiterbauen.

Gate 2 — nach der Beta (Ende Woche 3)

10 echte Nutzer aus dem Netzwerk haben installiert. Gemessen wird: Wie viele kommen ohne Hilfe bis zum Wow-Moment (Phase „Beweis“)?

Weiter, wenn: mindestens 8 von 10 ohne Support durchkommen. Sonst: Installer härten, bevor Ads skaliert werden — jeder Gescheiterte ist Rückerstattung + schlechte Bewertung.
